Pizza Hut is a pnpm monorepo for a customer-facing restaurant website and its Sanity content management studio.

## Applications

- [Web Application](/web/overview) — Next.js website with menu browsing, cart, checkout, reservations, newsletter signup, and support forms.
- [Sanity Studio](/studio/overview) — content management interface for products, categories, homepage content, and reservations.

## Quick Start

```bash
pnpm install
cd apps/web
pnpm run dev
```

Open `http://localhost:3000` to view the web application.
