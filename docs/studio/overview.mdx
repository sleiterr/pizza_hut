The Sanity Studio is the content management application for the Pizza Hut website. It provides editors with structured documents and a presentation view for managing site content.

## Responsibilities

- Manage homepage content and sections.
- Create and update menu products and categories.
- Maintain reservation-related content.
- Maintain product and menu item information consumed by the web application's menu chatbot.
- Provide Sanity Presentation Tool configuration for previewing the web application.

The chatbot interface and AI request handling live in the web application, not in Studio. Studio provides the Sanity content that grounds chatbot answers. See [Content Model](./content-model) for the chatbot's data sources and [Menu Chatbot](../web/chatbot) for the end-to-end flow.

## Main Directories

- `schemaTypes` — document and object schemas.
- `config` — Studio structure and Presentation Tool configuration.
- `presentation` — URL resolution for preview navigation.
- `static` — Studio static assets.
